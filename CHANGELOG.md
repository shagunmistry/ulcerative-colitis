# Changelog

What changed on the [live site](https://ulcerative-colitis.vercel.app), newest first.

## 2026-11-26

### Added

- [My UC Journal](/journal), a prototype that keeps entries on your device, with export,
  import, CSV copy and delete everything
- [Consent terms 0.1](https://github.com/shagunmistry/ulcerative-colitis/tree/main/spec/consent-terms),
  a draft format for terms that travel with exported data
- [Data commons](/commons) vision and roadmap, and a [Get involved](/get-involved) page
- Per-page [clinical review status](/reviewers) and a reviewer checklist
- [About](/about) page
- "Was this helpful?" on content pages
- Counts of five actions with no personal data, Vercel Speed Insights, and a `/stats` page
  that stays unlinked until its numbers are filled in
- Contributing guide, code of conduct, issue and pull request templates
- This changelog, and a citation check that runs on pull requests

### Changed

- The simulator's explanation is now a full [model card](/simulator/model) listing every number
- Outside links are always underlined, the 3D colon is described in words, and the 3D view
  stops gliding when reduced motion is requested
- The privacy page lists everything that is now measured

## 2026-11-25

### Added

- [Data library](/data) with licence, access and citation for each dataset
- [Live search](/data/search) of ClinicalTrials.gov, PubMed and Hugging Face

### Changed

- Feedback votes that nobody received were replaced with a GitHub report link

## 2026-11-24

### Added

- Plain-language topics with sources, trial results, search, further reading and the 3D
  teaching simulator
